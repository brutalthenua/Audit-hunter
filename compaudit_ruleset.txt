Here is a comprehensive set of **auditd rules** covering all 20 categories you specified. These rules are designed for **Ubuntu 20.04/22.04/24.04 LTS** and follow **CIS Benchmark** and **STIG** standards.

# **Complete Ubuntu Auditd Ruleset**
## **File Location:** `/etc/audit/rules.d/hardening.rules`
## **Apply Rules:** `sudo augenrules --load`

---

## **1. FILE SYSTEM MONITORING**
```bash
# Critical system files - All access
-w /etc/passwd -p wa -k identity
-w /etc/shadow -p wa -k identity
-w /etc/group -p wa -k identity
-w /etc/gshadow -p wa -k identity
-w /etc/sudoers -p wa -k sudoers
-w /etc/sudoers.d/ -p wa -k sudoers

# SSH and authentication
-w /etc/ssh/sshd_config -p wa -k sshd_config
-w /etc/ssh/ssh_config -p wa -k ssh_config
-w /root/.ssh/ -p wa -k ssh_keys
-w /home/*/.ssh/ -p wa -k ssh_keys

# Web server (if applicable)
-w /var/www/ -p wa -k web_content
-w /etc/apache2/ -p wa -k apache
-w /etc/nginx/ -p wa -k nginx

# System binaries
-w /bin/ -p wa -k system_binaries
-w /sbin/ -p wa -k system_binaries
-w /usr/bin/ -p wa -k system_binaries
-w /usr/sbin/ -p wa -k system_binaries

# Hidden file creation
-w /tmp/ -p wa -k tmp_watch
-w /var/tmp/ -p wa -k tmp_watch
-w /dev/shm/ -p wa -k tmp_watch
-w /home/ -p wa -k home_watch
```

## **5. SYSTEM CALL MONITORING (KERNEL LEVEL)**

## **Deployment Instructions**

1. **Save the rules:**
```bash
sudo nano /etc/audit/rules.d/hardening.rules
```

2. **Merge and load:**
```bash
sudo augenrules --load
```

3. **Verify:**
```bash
sudo auditctl -l
sudo auditctl -s
```

4. **Generate report:**
```bash
sudo aureport --summary
```

## **Key Adjustments Before Production**

1. **User-specific monitoring:** Uncomment and modify the `uid=` rules in Section 3 for specific high-risk users
2. **Web server paths:** Adjust if Apache/nginx are not used or are in different locations
3. **Container monitoring:** Adjust if using different container runtimes
4. **Performance tuning:** Consider increasing `-b 8192` if you experience backlog issues on busy systems

This ruleset provides **comprehensive coverage** across all 20 categories while maintaining **performance efficiency** through careful use of syscall auditing and path-based monitoring.
