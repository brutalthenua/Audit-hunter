# **How to USE Your Deployed Audit Rules**

Once your `hardening.rules` are deployed, here's exactly how to **USE** them for monitoring, investigation, and incident response:

---

## **📋 QUICK REFERENCE CARD**

| **Action** | **Command** |
|-----------|------------|
| Check if rules are active | `sudo auditctl -l \| wc -l` |
| Monitor live | `sudo tail -f /var/log/audit/audit.log` |
| Search by key | `sudo ausearch -k ssh_keys` |
| Today's events | `sudo ausearch -ts today \| aureport -f` |
| User activity | `sudo aureport -u` |
| Root commands | `sudo ausearch -k root_command` |

---

# **🔍 PART 1: SEARCHING & INVESTIGATING EVENTS**

## **By Category (Using Keys)**

Each rule has a `-k KEYNAME` tag. Use these to search:

### **Identity & Authentication**
```bash
# Who changed user accounts?
sudo ausearch -k identity -ts today

# SSH key modifications?
sudo ausearch -k ssh_keys -ts today

# Failed logins
sudo ausearch -k failed_logins -ts today | aureport -f

# Sudo usage
sudo ausearch -k privilege_escalation -ts today
```

### **File Activity**
```bash
# Files deleted today
sudo ausearch -k file_deletion -ts today

# Permission changes (chmod/chown)
sudo ausearch -k perm_mod -ts today

# Web directory changes
sudo ausearch -k web_content -ts today

# Temp directory abuse
sudo ausearch -k tmp_watch -ts today
```

### **Commands & Processes**
```bash
# All commands executed
sudo ausearch -k process_execution -ts today | less

# Suspicious tools (curl, wget, nc)
sudo ausearch -k lolbin -ts today

# Root commands
sudo ausearch -k root_command -ts today

# Compiler usage (gcc, make)
sudo ausearch -k compiler -ts today
```

### **Persistence & Backdoors**
```bash
# Cron job changes
sudo ausearch -k cron -ts today

# Systemd service modifications
sudo ausearch -k systemd -ts today

# Kernel module loading
sudo ausearch -k kernel_module -ts today

# SSH config changes
sudo ausearch -k ssh_config -ts today
```

### **Network Activity**
```bash
# Outbound connections
sudo ausearch -k outbound_connection -ts today

# Listening services
sudo ausearch -k socket_bind -ts today

# Host file modifications
sudo ausearch -k hosts -ts today
```

### **Anti-Forensics**
```bash
# Time changes (log tampering)
sudo ausearch -k time_change -ts today

# Log file modifications
sudo ausearch -k audit_log -ts today

# Bash history cleared
sudo ausearch -k bash_history -ts today
```

# **📊 PART 2: GENERATING REPORTS**

## **Daily Security Reports**
```bash
#!/bin/bash
# Save as: ~/audit-daily-report.sh

echo "=== AUDIT REPORT $(date) ==="

echo -e "\n▶️ Failed Logins:"
sudo aureport -l --failed -ts today

echo -e "\n▶️ Root Commands:"
sudo ausearch -k root_command -ts today --format text | grep exe | tail -20

echo -e "\n▶️ File Deletions:"
sudo ausearch -k file_deletion -ts today | aureport -f | tail -10

echo -e "\n▶️ Suspicious Tools:"
sudo ausearch -k lolbin -ts today --format text | grep exe | tail -10

echo -e "\n▶️ Permission Changes:"
sudo ausearch -k perm_mod -ts today | aureport -f | tail -10

echo -e "\n▶️ Cron Modifications:"
sudo ausearch -k cron -ts today | grep -E "crontab|cron" | tail -10
```

**Run daily:** `sudo bash ~/audit-daily-report.sh`

# **🚨 PART 3: INCIDENT RESPONSE SCENARIOS**

## **Scenario 1: Suspicious SSH Activity**
```bash
# 1. Check SSH logins
sudo aureport -l -ts today

# 2. Check SSH key modifications
sudo ausearch -k ssh_keys -ts today

# 3. Check SSH config changes
sudo ausearch -k ssh_config -ts today

# 4. Commands run by SSH users
sudo ausearch -m execve -ui $(whoami) -ts today

# 5. Outbound connections from SSH session
sudo ausearch -k outbound_connection -ts today | grep -B 5 sshd
```

## **Scenario 2: Possible Backdoor/Reverse Shell**
```bash
# 1. Check for LOLBin execution
sudo ausearch -k lolbin -ts today

# 2. Check outbound connections
sudo ausearch -k outbound_connection -ts today

# 3. Check for suspicious listening ports
sudo ausearch -k socket_bind -ts today

# 4. Check cron for persistence
sudo ausearch -k cron -ts today

# 5. Check systemd for new services
sudo ausearch -k systemd -ts today | grep -E "created|enabled"
```

## **Scenario 3: Privilege Escalation Attempt**
```bash
# 1. Check sudo usage
sudo ausearch -k privilege_escalation -ts today

# 2. Check SUID binary execution
sudo ausearch -k pkexec -k passwd -k su -ts today

# 3. Check for failed root attempts
sudo ausearch -m execve -ui 0 -sv no -ts today

# 4. Check permission changes to 777
sudo ausearch -k chmod_777 -ts today
```

## **Scenario 4: Data Exfiltration**
```bash
# 1. Check large file reads
sudo ausearch -k web_content -ts today | grep open | grep -E "\.(sql|tar|gz|zip|db)"

# 2. Check outbound connections
sudo ausearch -k outbound_connection -ts today

# 3. Check USB mounts
sudo ausearch -k usb_mount -ts today

# 4. Check compression tools
sudo ausearch -k lolbin | grep -E "tar|gzip|zip|base64" -ts today
```

# **📈 PART 4: MONITORING & ALERTS**

## **Real-time Monitoring**
```bash
# Watch live audit log (monitor in real-time)
sudo tail -f /var/log/audit/audit.log | grep --color=always -E "FAILED|DENIED|chmod 777|root"

# Monitor specific keys in real-time
sudo tail -f /var/log/audit/audit.log | grep "lolbin\|privilege_escalation\|kernel_module"
```

## **Create Simple Alerts**
```bash
# Create alert script
sudo tee /usr/local/bin/audit-alerts.sh << 'EOF'
#!/bin/bash

# Alert on root commands
if sudo ausearch -k root_command -ts recent -r > /dev/null; then
    echo "ALERT: Root command executed" | mail -s "Audit Alert" admin@localhost
fi

# Alert on LOLBin usage
if sudo ausearch -k lolbin -ts recent -r > /dev/null; then
    echo "ALERT: Suspicious tool used" | mail -s "Audit Alert" admin@localhost
fi

# Alert on failed logins
FAILED=$(sudo aureport -l --failed -ts recent | wc -l)
if [ $FAILED -gt 10 ]; then
    echo "ALERT: $FAILED failed logins" | mail -s "Brute Force Attempt?" admin@localhost
fi
EOF

sudo chmod +x /usr/local/bin/audit-alerts.sh

# Add to crontab (run every 5 minutes)
sudo crontab -e
# Add: */5 * * * * /usr/local/bin/audit-alerts.sh
```

# **🎯 PART 5: TARGETED INVESTIGATIONS**

## **Find Everything a User Did**
```bash
# Set the user you're investigating
USERNAME="john"

# Get their UID
USERID=$(id -u $USERNAME)

# All commands they ran
sudo ausearch -ui $USERID -k process_execution -ts yesterday,00:00 | aureport -x

# All files they accessed
sudo ausearch -ui $USERID -ts yesterday,00:00 | aureport -f

# When they logged in/out
sudo aureport -l -i | grep $USERNAME

# Sudo commands
sudo ausearch -ui $USERID -k privilege_escalation
```

## **Find Everything on a File**
```bash
# Track a specific file
FILENAME="/etc/passwd"

# Who accessed it?
sudo ausearch -f $FILENAME -ts today

# What was done to it?
sudo ausearch -f $FILENAME -ts today | aureport -f

# When was it modified?
sudo ausearch -f $FILENAME -ts today | grep -E "SYSCALL|PATH"
```

## **Find Everything at a Time**
```bash
# What happened at 3 AM?
sudo ausearch -ts 03:00 -te 03:10

# What happened during a specific hour?
sudo ausearch -ts 14:00 -te 15:00

# Weekend activity
sudo ausearch -ts last-weekend | aureport --summary
```

# **📚 PART 7: COMMAND CHEAT SHEET**

## **ausearch (Search)**
```bash
# By key
sudo ausearch -k ssh_keys

# By time
sudo ausearch -ts today
sudo ausearch -ts 09:00 -te 17:00
sudo ausearch -ts 01/15/2024

# By user
sudo ausearch -ui 1001
sudo ausearch -ua john

# By file
sudo ausearch -f /etc/passwd

# By syscall
sudo ausearch -m execve

# By exit code (failures)
sudo ausearch -sv no

# Combine filters
sudo ausearch -k process_execution -ui 1001 -ts today
```

## **aureport (Reports)**
```bash
# Summary
sudo aureport --summary

# User activity
sudo aureport -u

# Login activity
sudo aureport -l

# File access
sudo aureport -f

# Command execution
sudo aureport -x

# Time range
sudo aureport -ts today
sudo aureport -ts yesterday

# Failed events
sudo aureport --failed
```
